# How to Run

### Method 1: VS Code (Recommended)
1. Open the project in VS Code.
2. Ensure you have the **Extension Pack for Java** installed.
3. Open `src/main/java/com/vault/OcrFileReaderApplication.java`.
4. Click the **Run** button (Play icon) at the top right of the file.

### Method 2: Terminal (Portable)
If you do not have Maven installed on your system, use the provided wrapper:
```powershell
./mvnw spring-boot:run
```

Access the application at: `http://localhost:8080`
